# Baseline: экран → дефект → эталон (атлас)

| Экран | Дефект | Эталон |
|-------|--------|--------|
| Главная | Тёмный блок CTA (`.ask-block`) | Светлая surface-карточка, акцентная кнопка |
| Глобально | Inter + inline-градиент в `wallet.html` | Onest + `tokens.css`, фон `--paper` |
| Review / история | Двойной RU/EN месяц на `input[type=month]` | Только русская подпись, native скрыт |
| Review | `ВТБ · ВТБ` в контексте | `bank · card` если имена различаются |
| Add | Банки как простой текст | Строки `.bank-row`, 44px, разделители |
| Карты | Обрезка веера, жёсткая тень | Сцена выше, `transform-origin` 90%, padding |
| Toast | Накрывает «Сохранить» | Смещение при открытом review |
| Покупка | Дубли категории, длинные правила | Компактный победитель и однострочные альтернативы |
| История | Повтор месяца в сводке | Один месяц в пикере |
| Профиль | Без donut по картам | Donut + легенда из `stats.cards` |

Скриншоты: `home-*`, `cards-add-*`, `buy-*`, `demo-fan-*` (320/390/430/1280).
