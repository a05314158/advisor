# Советник — какую карту выбрать перед оплатой

Веб-версия MVP для кейса PROD. Покупатель выбирает категорию и вводит сумму. Сервис сравнивает ожидаемый возврат **в рублях** по всему учебному каталогу или только по своим картам. В «Моих картах» можно сохранить карту из справочника или ввести свои условия с произвольными категориями. Платёж происходит вне сервиса.

Под результатом откройте «Условия», чтобы увидеть сумму по ставке до ограничений и шаги, на которых сработали лимиты. После расчёта в аккаунте можно перенести сумму и категорию в журнал. Оплаченную карту пользователь указывает сам.

## Выбор банка

При добавлении своей карты можно найти банк по названию или регистрационному номеру. Список из `banks_ru.json` основан на [реестре Банка России](https://www.cbr.ru/banking_sector/credit/FullCoList). Ставки и лимиты вводятся вручную или сверяются после распознавания снимка из банка.

## Переход в банк

В результатах покупки «Веб-кабинет банка» открывает официальный кабинет Т‑Банка, Альфа‑Банка, Сбера или ВТБ. Покупку в журнале сохраняет отдельная кнопка «Выбрать».

На странице `/bank-link-test` можно проверить кандидаты для запуска приложений на Android и iPhone и вручную записать результат. Результаты хранятся на устройстве и выгружаются в JSON.

## Месячный лимит

Откройте **Мои карты → Условия и лимит**. Можно изменить ставку активной категории ручной карты. Общий лимит и уже начисленный кэшбэк хранятся отдельно от ставки. Начисления относятся к календарному месяцу UTC. Пустые начисления означают, что расчёт использует полный указанный лимит. Когда остаток равен нулю, карта даёт 0 ₽. При смене месяца общий лимит сохраняется.

## Покупки и прогноз

В режиме «Мои карты» кнопка «Выбрать» сохраняет оценку покупки в журнале. «Мои карты → Статистика» показывает сумму по выбранным картам и сравнение с лучшими вариантами. «План кешбэка на месяц» сравнивает подтверждённые категории с предложениями банков и использует историю или введённые суммы. Сверка ставок и фактических начислений выполняется пользователем.

## Локальный запуск

Python 3.11+. Из корня проекта:

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python -m uvicorn advisor:app --host 127.0.0.1 --port 8766
```

Откройте http://127.0.0.1:8766. База создаётся при первом запуске и по умолчанию хранится в `advisor.sqlite3`. Для стенда укажите `ADVISOR_DB` на постоянном диске, используйте HTTPS за прокси и проверяйте `/healthz`. Перед обновлением остановите сервис и сохраните копию базы; для отката восстановите совместимую копию базы и предыдущую сборку.

## Стенд PROD

GitHub Actions запускает тесты после изменений. Прошедший тесты коммит из `main` публикуется в `deploy/staging`. ВМ проверяет эту ветку раз в минуту, запускает новую версию и сверяет SHA и расчёт для 2 500 ₽ в супермаркете с действующим каталогом. При сбое возвращается к предыдущему релизу. GitHub не хранит ключ доступа к ВМ. SQLite на ВМ лежит отдельно от релизов в `/var/lib/advisor/advisor.sqlite3`.

Проверить, какая версия работает на ВМ, можно по полю `revision` в ответе `/healthz`. Его значение совпадает с SHA развёрнутого коммита.

После появления ветки `deploy/staging` клонируйте её на ВМ и запустите `sudo bash deploy/install.sh <имя-ВМ>.vm.prodcontest.com`. Если веб-порты свободны, скрипт настроит Caddy и обратный прокси. Для выдачи публичного сертификата домен и порты 80/443 должны быть доступны извне. Если Spirit уже обслуживает веб-порты, используйте существующую HTTPS-публикацию с прокси до приложения на порту 8766. Для обновления скрипта проверки повторно запустите установщик из нового релиза. Состояние обновлений видно через `sudo journalctl -u advisor-update.service -n 30 --no-pager`.

Импорт обновлений: `python -m catalog rules.json --db advisor.sqlite3`. JSON — массив объектов с полями `cardId`, `categoryId`, `rateBps`, `limitKopecks`, `minAmountKopecks`, `validFrom`, `validUntilExclusive`, `updatedOn`. Чтобы задать названия карточки и банка, передайте оба поля `cardName` и `bankName` хотя бы в одном её правиле. Значения учебного примера есть в `catalog.py`; ключ и правила периодов описаны в [контракте](docs/contract.md). Повторный запуск приложения не перезаписывает импорт. Учебный seed действует до 1 ноября 2027 UTC, не включая эту дату. Ручные данные хранятся на сервере в кошельке аккаунта. Восстановление пароля пока не реализовано. См. [Backend: эксплуатация и критерии](docs/backend.md).

## Как проверить MVP

1. Создайте кошелёк, откройте «Покупка → Весь каталог», выберите «Супермаркеты» и введите 2 500 ₽. Учебный топ — B 150 ₽, A 100 ₽, C 100 ₽. В полном списке также D 50 ₽.
2. Откройте «Условия» у A. По ставке получилось 250 ₽, лимит уменьшил прогноз до 100 ₽. Смените категорию на «Кафе» — останется D.
3. В «Моих картах» добавьте свой банк и введите активную ставку вручную. В «Условия и лимит» задайте лимит и начисления, затем измените ставку. После перезагрузки повторите покупку в режиме «Мои карты» и проверьте новый рейтинг и прежний остаток.

## Что сдаём

| Обязательно | Признак готовности |
|---|---|
| Каталог на сервере: банк, карта, категории, ставки, ограничения, лимиты и даты | Импорт повторяем; устаревшее не становится действующим; справочник рассчитан на сотни карт |
| Мобильный экран категории и суммы, серверное ранжирование | Топ-3, полный отфильтрованный список, подробные условия и дата; видно, почему победила карта |
| «Мои карты» | На сервере сохраняются ссылки на карты каталога и вручную введённые условия для текущей сессии. После перезагрузки сравнивается тот же набор |
| Доступная сборка | Ссылка открывается на чужом телефоне, данные переживают рестарт, чистый запуск описан |

Для расчёта нужна сумма. Условия каталога учебные, возврат расчётный. Номер карты, CVV, SMS и другие платёжные секреты сервис не запрашивает. Основной сценарий работает на подготовленных данных без банковских API и платных внешних сервисов.

После приёмки P0: локальная подсказка категории по бренду (не подтверждает MCC); проверенный официальный переход в приложение банка (не платёж); явная запись покупки и отчёт относительно обычной карты с сохранённой версией условий. При нехватке времени исключить всё это, а не деплой или «Мои карты».
