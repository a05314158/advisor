# Советник — какую карту выбрать перед оплатой

Статус: локальная версия MVP. Покупатель выбирает категорию и вводит сумму. Сервис сравнивает ожидаемый возврат **в рублях** по всему учебному каталогу или только по своим картам. В «Моих картах» можно сохранить карту из справочника или ввести свои условия с произвольными категориями. Платёж происходит вне сервиса.

Под результатом откройте «Условия», чтобы увидеть сумму по ставке до ограничений и шаги, на которых сработали лимиты. После расчёта в аккаунте можно перенести сумму и категорию в журнал. Оплаченную карту пользователь указывает сам.

## Выбор банка

Справочник банков для ручного добавления карт основан на [реестре Банка России](https://www.cbr.ru/banking_sector/credit/FullCoList) за 20 ноября 2026 года. Поиск работает по названиям, известным алиасам и регистрационным номерам. Данные хранятся в файле banks_ru.json и выдаются через /api/banks. Проценты и лимиты пользователь указывает по своим условиям.

## Переход к оплате

Для лучшей из своих карт Т‑Банка и Альфа‑Банка доступна ссылка в официальный веб-кабинет. Для карты Т‑Банка доступно «Оплатить через T‑Pay», если продавец выдал готовую ссылку T‑Pay. СБП из рекомендации исключена: обычный карточный кэшбэк за такую оплату не начисляется. Дальнейший переход в приложение или веб-форму выполняет поставщик ссылки. Покупатель проверяет получателя, сумму и счёт и подтверждает оплату на стороне банка. Советник не создаёт платёж, не получает его статус и не сохраняет платёжную ссылку.

## Месячный лимит

Общий лимит можно задать при создании ручной карты или позже в «Моих картах», в том числе для сохранённой карты из каталога. Там же укажите, сколько банк уже начислил за календарный месяц UTC по всем категориям карты. Пустое поле означает неизвестный остаток (расчёт предполагает полный указанный лимит); `0` означает подтверждённое отсутствие начислений. Если лимит не указан, месячный остаток не учитывается. При известном нулевом остатке карта исключается из личных рекомендаций. В новом месяце лимит сохраняется, а начисления считаются неизвестными до ввода. Режим «Весь каталог» не использует личные условия. Расчёт не меняет сохранённые суммы и не загружает начисления из банка.

В «Моих картах» можно отдельно изменить ставку категории ручной карты. Идентификатор, остальные правила и введённые начисления за месяц сохраняются.

## Статистика трат

Войдите в аккаунт и выберите «Статистика трат → Записать покупку». Укажите дату, сумму, категорию и при желании — место и использованную карту. В отчёте за календарный месяц видны общая сумма, крупнейшая покупка, разбивка по категориям, местам и картам. Рейтинг сравнивает, сколько дала бы каждая карта при оплате всех записанных покупок: сохраняются оценки по условиям, известным на момент записи, а на итог применяется общий месячный лимит карты (при разнице в сохранённых лимитах — наименьший из известных). Уже начисленный кэшбэк и незаписанные покупки не входят в эту симуляцию. Журнал не меняет использованный остаток и не загружает банковские выписки. У отдельной записи можно сравнить выбранную карту с лучшей для этой покупки по сохранённым условиям. В пооперационном сравнении учитывается лимит на покупку, месячный остаток не восстанавливается. Доступных данных может не хватать для сравнения.

## Локальный запуск

Python 3.11+. Из корня проекта:

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python -m uvicorn advisor:app --host 127.0.0.1 --port 8766
```

Откройте http://127.0.0.1:8766. База создаётся при первом запуске и по умолчанию хранится в `advisor.sqlite3`. Для стенда укажите `ADVISOR_DB` на постоянном диске, используйте HTTPS за прокси и проверяйте `/healthz`. Перед обновлением остановите сервис и сохраните копию базы; для отката восстановите совместимую копию базы и предыдущую сборку.

## Стенд PROD

GitHub Actions запускает тесты после изменений. Прошедший тесты коммит из `main` публикуется в `deploy/staging`. ВМ проверяет эту ветку раз в минуту, запускает новую версию и сверяет SHA и расчёт для 2 500 ₽ в супермаркете с действующим каталогом. При сбое возвращается к предыдущему релизу. GitHub не хранит ключ доступа к ВМ. SQLite на ВМ лежит отдельно от релизов в `/var/lib/advisor/advisor.sqlite3`.

Проверить, какая версия работает на ВМ, можно по полю `revision` в ответе `/healthz`. Его значение совпадает с SHA развёрнутого коммита.

После появления ветки `deploy/staging` клонируйте её на ВМ и запустите `sudo bash deploy/install.sh <имя-ВМ>.vm.prodcontest.com`. Если веб-порты свободны, скрипт настроит Caddy и обратный прокси. Для выдачи публичного сертификата домен и порты 80/443 должны быть доступны извне. Если Spirit уже обслуживает веб-порты, используйте существующую HTTPS-публикацию с прокси до приложения на порту 8766. Для обновления скрипта проверки повторно запустите установщик из нового релиза. Состояние обновлений видно через `sudo journalctl -u advisor-update.service -n 30 --no-pager`.

Импорт обновлений: `python -m catalog rules.json --db advisor.sqlite3`. JSON — массив объектов с полями `cardId`, `categoryId`, `rateBps`, `limitKopecks`, `minAmountKopecks`, `validFrom`, `validUntilExclusive`, `updatedOn`. Чтобы задать названия карточки и банка, передайте оба поля `cardName` и `bankName` хотя бы в одном её правиле. Значения учебного примера есть в `catalog.py`; ключ и правила периодов описаны в [контракте](docs/contract.md). Повторный запуск приложения не перезаписывает импорт. Учебный seed действует до 1 ноября 2027 UTC, не включая эту дату. В гостевом режиме список «Мои карты» привязан к cookie браузера. После входа карты хранятся под ID аккаунта и доступны при входе на другом устройстве на том же сервере. При регистрации можно явно перенести гостевые карты. Восстановление пароля пока не реализовано. См. [Backend: эксплуатация и критерии](docs/backend.md).

## Рекомендация из каталога

Когда сохранённые карты не дают положительного возврата, «Советник» показывает отдельную рекомендацию из каталога, если для той же покупки есть подходящие условия. Учебный каталог используется для демонстрации и не содержит ссылок на оформление.

## Что сдаём

| Обязательно | Признак готовности |
|---|---|
| Каталог на сервере: банк, карта, категории, ставки, ограничения, лимиты и даты | Импорт повторяем; устаревшее не становится действующим; справочник рассчитан на сотни карт |
| Мобильный экран категории и суммы, серверное ранжирование | Топ-3, полный отфильтрованный список, подробные условия и дата; видно, почему победила карта |
| «Мои карты» | На сервере сохраняются ссылки на карты каталога и вручную введённые условия для текущей сессии. После перезагрузки сравнивается тот же набор |
| Доступная сборка | Ссылка открывается на чужом телефоне, данные переживают рестарт, чистый запуск описан |

Для расчёта нужна сумма. Условия каталога учебные, возврат расчётный. Номер карты, CVV, SMS и другие платёжные секреты сервис не запрашивает. Основной сценарий работает на подготовленных данных без банковских API и платных внешних сервисов.

После приёмки P0: локальная подсказка категории по бренду (не подтверждает MCC); проверенный официальный переход в приложение банка (не платёж); явная запись покупки и отчёт относительно обычной карты с сохранённой версией условий. При нехватке времени исключить всё это, а не деплой или «Мои карты».
