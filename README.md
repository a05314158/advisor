# Советник — какую карту выбрать перед оплатой

Статус: локальная версия MVP; публичный деплой не выполнен. Покупатель выбирает категорию и вводит сумму; сервис сравнивает ожидаемый возврат **в рублях**, а не рекламные проценты. На главном экране сравниваются только карты, введённые вручную. У каждой карты свой банк и произвольное число категорий. Для каждой ставки можно задать минимум покупки, лимит кэшбэка и период действия; конечная дата не включается. Пустое начало означает дату сохранения по UTC. Категории покупки берутся из сохранённых карт; экран показывает победителя, топ до трёх и полный список. API учебного каталога оставлен для совместимости. Платёж происходит вне сервиса.

## Месячный лимит

В «Моих картах» раскройте карту и задайте общий лимит возврата и сумму, уже начисленную за текущий календарный месяц UTC. Это сумма по всем категориям карты. Калькулятор ограничивает прогноз остатком, исключает карту при нулевом остатке и не меняет начисленную сумму. В новом месяце сумма начинается с нуля, лимит сохраняется. Начисления из банка не загружаются. Без указанного общего лимита расчёт учитывает только правила категории.

## Локальный запуск

Python 3.11+. Из корня проекта:

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python -m uvicorn advisor:app --host 127.0.0.1 --port 8766
```

Откройте http://127.0.0.1:8766. База создаётся при первом запуске и по умолчанию хранится в `advisor.sqlite3`. Для стенда укажите `ADVISOR_DB` на постоянном диске, используйте HTTPS за прокси и проверяйте `/healthz`. Перед обновлением остановите сервис и сохраните копию базы; для отката восстановите совместимую копию базы и предыдущую сборку.

Импорт обновлений: `python -m catalog rules.json --db advisor.sqlite3`. JSON — массив объектов с полями `cardId`, `categoryId`, `rateBps`, `limitKopecks`, `minAmountKopecks`, `validFrom`, `validUntilExclusive`, `updatedOn`. Значения учебного примера есть в `catalog.py`; ключ и правила периодов описаны в [контракте](docs/contract.md). Повторный запуск приложения не перезаписывает импорт. Учебный seed действует до 1 ноября 2027 UTC, не включая эту дату. В гостевом режиме список «Мои карты» привязан к cookie браузера. После входа карты хранятся под ID аккаунта и доступны при входе на другом устройстве на том же сервере. При регистрации можно явно перенести гостевые карты. Восстановление пароля пока не реализовано. См. [Backend: эксплуатация и критерии](docs/backend.md).

## Что сдаём

| Обязательно | Признак готовности |
|---|---|
| Каталог на сервере: банк, карта, категории, ставки, ограничения, лимиты и даты | Импорт повторяем; устаревшее не становится действующим; справочник рассчитан на сотни карт |
| Мобильный экран категории и суммы, серверное ранжирование | Топ-3, полный отфильтрованный список, подробные условия и дата; видно, почему победила карта |
| «Мои карты» | На сервере сохраняются только ссылки на карты каталога для текущей сессии. После перезагрузки сравнивается тот же набор |
| Доступная сборка | Ссылка открывается на чужом телефоне, данные переживают рестарт, чистый запуск описан |

Без суммы не обещаем точного победителя. Условия учебные; прогноз не является начислением. Не запрашивать номер карты, CVV, SMS и другие платёжные секреты. Не использовать банковские API, NFC, реальные транзакции, геолокацию, LLM, Spirit или обязательные платные сервисы.

После приёмки P0: локальная подсказка категории по бренду (не подтверждает MCC); проверенный официальный переход в приложение банка (не платёж); явная запись покупки и отчёт относительно обычной карты с сохранённой версией условий. Остаток месячного лимита — отдельная функция. При нехватке времени исключить всё это, а не деплой или «Мои карты».
