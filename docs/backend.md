# Backend: эксплуатация и критерии

## Аккаунты

`POST /api/auth/register` и `POST /api/auth/login` принимают `login` и `password`. Пароль сохраняется в PBKDF2-хеше с индивидуальной солью. Cookie имеет флаги HttpOnly и SameSite=Strict, а на HTTPS также Secure. Кошельки разделены по аккаунту. Журнал старой версии сохраняется в базе отдельно от журнала нового кошелька.

## Наблюдаемость

Запуск: `python -m uvicorn advisor:app --host 127.0.0.1 --port 8771 --no-access-log`. Сервис пишет JSON-событие на запрос: время UTC, ID из `X-Request-ID`, шаблон маршрута, метод, статус, время обработки; для необработанного сбоя — класс ошибки. Без тел запросов, логинов, паролей, cookies и карт. Отключите также запись чувствительных полей во внешнем прокси.

- `/healthz` проверяет доступность SQLite. `/metrics` отдаёт число запросов и время обработки в формате Prometheus. Метрики процесса сбрасываются при рестарте; на публичном стенде ограничьте `/metrics` на прокси до доступа сборщика.
- После релиза проверьте `/healthz`, вход на втором устройстве и наличие метрик. При 5xx найдите событие по `X-Request-ID`. Для Grafana полезны поток запросов, доля 5xx и среднее время по маршруту (производная суммы / производная числа запросов). Алерт на недоступность health-check и рост 5xx пока не настроен.

## Сдача по «Критерии.pdf», стр. 1–2

- **Архитектура и релиз:** приложение и SQLite с миграцией при старте. Для публичного запуска — один процесс, постоянный диск, HTTPS и доверенный прокси с сохранением Host и схемы. Ограничение попыток входа сейчас локально для процесса; для публичного стенда поставьте ограничение на прокси. Перед релизом остановите процесс, сделайте защищённую копию базы, запустите новую версию и проверьте `/healthz`. Для отката восстановите совместимую сборку и копию базы. Копия содержит пользовательские данные; не загружайте её в Git.
- **Инженерное качество:** зависимости, OpenAPI (`/docs`), unit- и интеграционные тесты (`python -m unittest -q`). GitHub Actions проверяет архив релиза и публикует его в `deploy/staging`. ВМ забирает только эту ветку.
- **Наблюдаемость:** JSON-логи + базовые метрики + поиск по ID запроса реализованы. Централизованный сбор, дашборд и алерты на стенде не проверены.
- **Техническая оригинальность:** можно показать пересчитываемый рейтинг по личным условиям, лимитам и датам, а не выдавать обычную регистрацию за отличительную особенность.
