Проверка запуска банков

Откройте страницу в Chrome на Android. Нажмите «Проверить запуск» для установленного банка. Если открылся веб-кабинет, сработал запасной переход. Вернитесь назад, чтобы проверить следующий банк.

  • Альфа-БанкПроверить запуск Альфа-БанкОткрыть веб-кабинет
  • СберПроверить запуск СберОткрыть веб-кабинет
  • ВТБПроверить запуск ВТБОткрыть веб-кабинет
